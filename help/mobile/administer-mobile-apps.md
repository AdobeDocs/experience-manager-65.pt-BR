# Aplicativos móveis{#mobile-apps}

{{ue-over-mobile}}

O Adobe Experience Manager (AEM) Mobile faz parte da plataforma digital multicanal da Adobe Experience Manager que também usa o AEM Assets, Sites, Screens, Fluxo de trabalho, Gerenciador de usuários, Commerce e Forms. O AEM Mobile oferece flexibilidade de implantação notável, permitindo que as empresas usem uma variedade de fontes de conteúdo.

O AEM Mobile oferece vários métodos para criar aplicativos. As diferentes maneiras de criar aplicativos são:

* [Administração de conteúdo para o AEM Mobile On-demand Services](/help/mobile/aem-mobile.md)
* [Administração de conteúdo para o Adobe PhoneGap Enterprise com o AEM](/help/mobile/administer-phonegap.md)

>[!NOTE]
>
>Se você é novo no Adobe Experience Manager, talvez queira apresentar a [Introdução ao AEM](/help/sites-deploying/deploy.md).
